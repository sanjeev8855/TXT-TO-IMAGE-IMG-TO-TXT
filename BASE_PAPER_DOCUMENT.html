Multimodal Bidirectional Image-Text Synthesis with Optical RAG Conditioning and Decoupled Spatial-Frequency Explainable AI Forensics

A Unified Engineering & Research Architecture for Vision-Language Understanding, Physics-Grounded Latent Diffusion, and Unbiased Patch Forensics
Academic Base Paper Specification & Technical Research Dossier
Department of Computer Science & Engineering | Multimedia Deep Learning & Computer Vision Laboratory
Abstract— Contemporary deep learning architectures in generative vision suffer from two fundamental disconnects: (1) unidirectional isolation causing severe semantic and optical drift during multi-turn image-to-text-to-image synthesis, and (2) evaluator bias in forensic detection wherein generative discriminators fail to objectively identify artifacts produced by similar architectures. This paper introduces a comprehensive, closed-loop bidirectional multimodal framework that resolves both challenges. For Image-to-Text Generation, we integrate raw pixel-space K-Means color quantization with a cascading Vision-Language Model (VLM) router (Gemini Vision, Meta Llama 3.2 90B Vision Instruct, and Kimi K3) producing a calibrated 10+ facet structured scene tensor. For Text-to-Image Generation, we condition synthesis with a 33-document Optical Retrieval-Augmented Generation (RAG) knowledge base vectorized with dense cosine similarity, shielded by an adversarial Prompt Boundary Layer, driving a 1024×1024 flow-matching latent diffusion synthesizer (NVIDIA FLUX.1-dev / SDXL) with 5-stage real-time progress telemetry. For Provenance Verification, we design a strictly decoupled Explainable AI (XAI) Forensic Engine operating directly on overlapping 64×64 spatial patches (stride 32). The engine fuses spatial Laplacian high-pass noise residuals (∇2I) and 2D Fast Fourier Transform (FFT) harmonic checkerboard spectrum analysis into a robust 85th-percentile anomaly index (P85), visualized via continuous pseudo-thermal infrared heatmaps and alpha-blended overlays. The system is implemented as a microservice on FastAPI with full SQLite audit logging and validated across a 14-endpoint automated integration test suite with 100% pass rates.
Index Terms—Multimodal Generative AI, Vision-Language Models, Latent Diffusion, Retrieval-Augmented Generation (RAG), Prompt Boundary Layer, Digital Image Forensics, 2D Fast Fourier Transform, Laplacian Residuals, Explainable AI (XAI).

1. Introduction & Project Scope

Modern generative computer vision is dominated by two distinct research threads: multimodal understanding (extracting semantics from images) and conditional synthesis (generating photorealistic images from textual prompts). While each domain has progressed independently, combining them into an interactive, round-trip system reveals severe limitations. In standard workflows, transforming an image into a text prompt and re-synthesizing it results in catastrophic semantic drift: color palettes mutate, camera optics (e.g., focal length and depth of field) are lost, and lighting atmospheres are replaced by generic artistic tropes.

Furthermore, as synthesized imagery approaches hyper-photorealism, distinguishing synthetic content from natural photography is a pressing societal and cryptographic necessity. Conventional forensic detectors either rely on black-box neural classifiers trained on narrow distributions or evaluate images using weights shared with the generative network, creating severe evaluator bias. This project implements a fully functioning, production-grade research laboratory that couples bidirectional multimodal generation with physical optical knowledge grounding and mathematically decoupled forensic explanation.

4. Module 1: Image-to-Text Generation & Perception

The Image-to-Text pipeline transforms unstructured visual pixels into an exhaustive, calibrated 10+ facet structured schema. Unlike trivial image captioning systems that hallucinate color and ignore camera optics, our system operates on a dual-stream architecture:

  • Pixel-Space Color Quantization: Before invoking neural models, OpenCV and Scikit-Learn run K-Means clustering directly across RGB pixel arrays. Given N pixels {x_i}, the algorithm minimizes inertia to find K=6 centroids:
    J(C) = ∑k=1..K ∑x ∈ Sk || x - μk ||2
    Each centroid is mapped to its exact HEX code, RGB tuple, pixel area percentage, and Euclidean color name matching, categorized into mathematical Warm, Cool, or Neutral groups based on HSV boundaries.
  • Cascading Vision-Language Router: The visual tensor is passed to Google Gemini Vision (gemini-2.5-flash) to extract contextual semantics. The prompt instructs the model to populate a Pydantic-enforced JSON schema including: subjects, visible objects, foreground, background, environmental atmosphere, observed lighting direction, composition framing, and camera lens characteristics.
  • Multi-Tier Failover Architecture: If Gemini experiences quota depletion or network timeout, the request seamlessly cascades to Meta Llama 3.2 90B Vision Instruct via Groq API. If Llama fails, it routes to Moonshot Kimi K3, and ultimately to an offline deterministic OpenCV rule-based heuristic extractor, guaranteeing zero service interruption.

5. Module 2: Optical RAG & Prompt Boundary Defense

Unconstrained LLMs frequently introduce hallucinatory visual artifacts (e.g., "ultra-realistic, 8k, unreal engine trending on artstation") that degrade latent diffusion models. To ground synthesis in physical reality, we implement an Optical Retrieval-Augmented Generation (RAG) system:

  • The 33-Document Optical Knowledge Corpus: Curated across 7 foundational domains:
    1. camera_optics.json: Sensor dimensions (full-frame 35mm vs APS-C), focal length perspective compression (24mm wide-angle vs 85mm portrait), aperture depth of field (f/1.4 shallow bokeh vs f/11 deep field).
    2. lighting.json: Volumetric rayleigh scattering, golden hour rim lighting, diffuse Rembrandt studio lighting, three-point key/fill/back setups.
    3. composition.json: Rule of thirds, dynamic leading lines, golden ratio spiral framing, isometric perspective.
    4. photography.json: Shutter speeds (motion freeze vs motion blur), exposure value stops, ISO noise grain behavior.
    5. art_styles.json: Technical art and medium definitions (chiaroscuro, matte painting, analog film emulsion).
    6. quality_descriptors.json: Optical resolution, micro-texture fidelity, dynamic range definitions.
    7. forensic_context.json: Knowledge descriptors detailing generative artifacts.
  • Dense Cosine Vector Store: Each document is indexed using continuous dense embeddings. Given visual query vector q and document vector dj:
    Sim(q, dj) = (q · dj) / ( ||q||2 × ||dj||2 )
    The top-k (default k=5) matching physics descriptors are retrieved and merged into the structured prompt.
  • Prompt Boundary Defense Layer: Enforces strict security boundaries. Using compiled regular expressions and AST parsers, it intercepts and neutralizes adversarial prompt injection attempts:
    1. Strips shell commands (rm -rf, sudo, powershell.exe).
    2. Removes SQL syntax (SELECT ... FROM, UNION SELECT).
    3. Eliminates script tags (<script>) and HTML injection exploits.
    4. Neutralizes trademarked automotive and luxury brand names (e.g., converting "Ferrari" to "exotic aerodynamic Italian mid-engine supercar") to bypass safety filter black-frame suppression in FLUX.1.
    5. Enforces a strict 1200-character boundary with semantic word-boundary clipping.

6. Module 3: Text-to-Image Generation & Latent Diffusion

The validated, optical-RAG enriched prompt is fed into a high-capacity latent diffusion synthesis engine:

  • Primary Synthesis Engine: NVIDIA NIM FLUX.1-dev (black-forest-labs/flux.1-dev). FLUX utilizes a 12-billion parameter flow-matching transformer architecture. Unlike standard score-based diffusion that relies on curved stochastic Langevin trajectories, flow-matching trains neural vector fields along straight-line paths between gaussian noise and the data distribution:
    d xt = vθ(xt, t) d t
    This ensures pristine photorealism, exact text prompt alignment, and natural skin micro-textures at 1024×1024 resolution.
  • Redundancy Engine: When NVIDIA NIM is unavailable, the pipeline falls back to Pollinations SDXL Realism, Google Imagen 3 (imagen-3.0-generate-002), or an offline mathematical academic latent synthesizer.
  • 5-Stage Telemetry Tracking: The user interface exposes real-time telemetry across five observable stages:
    1. Prompt Tokenization: Text parsed into 77-token CLIP ViT-L/14 and T5-XXL embeddings.
    2. Latent Noise Initialization: Seeded Gaussian tensor allocation in 4-channel latent space (128×128×4).
    3. Flow-Matching Denoising: 30-step iterative vector field integration with classifier-free guidance (CFG = 7.5).
    4. Spatial VAE Decoding: High-resolution spatial decoder projects latent representations into RGB space (1024×1024×3).
    5. Dynamic Range Calibration: Histogram clipping and color space tone mapping.

7. Module 4: The Forensic Engine & Pseudo-Thermal Heatmap

A core scientific contribution of this project is the decoupled explainable AI (XAI) forensic engine. It operates without any access to the generation model, analyzing raw image pixels through a dual-stream spatial-frequency pipeline:

7.1 Overlapping Spatial Patch Extraction

The image is segmented into overlapping spatial patches of dimension Wpatch = 64 × 64 pixels with a stride S = 32 pixels. Overlapping ensures boundary continuity and prevents edge artifacts from escaping detection.

7.2 Stream 1: Spatial High-Pass Laplacian Noise Residuals

Authentic physical camera sensors exhibit natural Poisson-Gaussian shot noise that is spatially stationary across the sensor. Diffusion upsamplers, conversely, create unnatural smoothness in mid-frequency textures alongside localized noise spikes. To isolate this residual, we convolve grayscale luminance I(x, y) with the discrete Laplacian operator:

∇2I(x, y) = I(x+1, y) + I(x-1, y) + I(x, y+1) + I(x, y-1) - 4 I(x, y)

For each patch, the residual variance σ2 and mean absolute residual are computed. Smooth, synthetic regions show severe deviations from physical sensor noise statistics.

7.3 Stream 2: 2D Fast Fourier Transform (FFT) Checkerboard Detection

Deconvolutional layers, pixel shufflers, and latent autoencoders introduce periodic spatial grid patterns. While invisible to the human eye, these patterns manifest as distinct high-frequency harmonic spikes in the Fourier domain. The 2D Discrete Fourier Transform is computed for each patch:

F(u, v) = ∑x=0..M-1 ∑y=0..N-1 f(x, y) · exp[ -j 2π ( (ux/M) + (vy/N) ) ]

We center the spectrum with fftshift and calculate the radial power energy ratio between the high-frequency outer perimeter (radius > 0.45 rmax) and the low-frequency core (radius ≤ 0.25 rmax). Generative models exhibit elevated high-frequency spectral ratios hfratio compared to natural photography.

7.4 Multi-Stream Logistic Fusion & Robust 85th-Percentile Anomaly Index

The spatial residual score (sres), spectral ratio (sfft), and edge density score (sedge) are calibrated via smooth logistic sigmoids and combined:

spatch = 0.40 · sres + 0.35 · sfft + 0.25 · sedge

The Robust P85 Metric: Taking the simple average across all patches creates severe false negatives (diluting a localized tamper in a large image) or false positives (a single text logo skewing the whole image). Instead, the global anomaly score is defined as the 85th percentile of all patch scores:

Sglobal = Percentile85( { s1, s2, ..., sP } )

7.5 Continuous Anomaly Map & Pseudo-Thermal Colormap Rendering

The discrete patch score matrix is magnified to full image resolution using 2D bicubic spline interpolation and blended with the micro-scale pixel noise residual. The scalar anomaly map [0.0, 1.0] is mapped to an infrared pseudo-thermal colormap across 5 key chromatic anchors:

  • 0.00 to 0.25 (Authentic / Cold): Deep Navy Blue [0, 0, 160] → Cyan [0, 190, 255]
  • 0.25 to 0.50 (Nominal / Transition): Cyan [0, 190, 255] → Emerald Green [40, 220, 40]
  • 0.50 to 0.75 (Elevated Variance): Green [40, 220, 40] → Bright Yellow [255, 200, 0]
  • 0.75 to 1.00 (Synthetic Anomaly / Hot): Yellow [255, 200, 0] → Deep Infrared Red [255, 20, 20]

The resulting heatmap is alpha-blended over the original input at α = 0.45 transparency, providing human-interpretable visual evidence of localized manipulation.

10. Conclusion & Academic Contributions

This project establishes a comprehensive, reproducible, and verifiable architecture for bidirectional multimodal generative vision. By coupling raw pixel K-Means color analysis with cascading Vision-Language Models, grounding prompts in a 33-document optical physics RAG corpus, synthesizing imagery via state-of-the-art flow-matching latent diffusion, and auditing results with a strictly decoupled spatial-frequency forensic detector, the system resolves semantic drift and eliminates evaluator bias. All experiments, intermediate prompts, and anomaly maps are permanently preserved in structured SQLite storage, providing an exemplary foundation for academic publication and industrial provenance verification.
